# Tier 1 — Basic Understanding: The Python Launchpad

## 1. Introduction to Python
Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum and first released in 1991. Its clean, readable syntax looks close to everyday English, making it easy for beginners to focus on problem-solving rather than complex punctuation[cite: 6].

## 2. Why Python Is Significant
- **Beginner-Friendly Learning Curve:** Clear syntax makes it great for first-time programmers[cite: 6].
- **Wide Industry Use:** Used in web development, data science, artificial intelligence, machine learning, and automation[cite: 6].
- **Rich Ecosystem:** Thousands of ready-to-use libraries (such as on PyPI) speed up development[cite: 6].
- **Cross-Platform:** Code written on one operating system can run across Windows, macOS, and Linux[cite: 6].

## 3. What a Beginner Needs Before Writing Python Programs
1. **Python Interpreter:** The software downloaded from `python.org` that runs your Python code[cite: 6].
2. **Code Editor or IDE:** A place to write and save code, such as **IDLE** (included with Python) or **VS Code**[cite: 6].
3. **Terminal / Command Line:** Used to run scripts and check your setup (Command Prompt/PowerShell on Windows; Terminal on macOS and Linux)[cite: 6].

## 4. How Python Is Run
Python is an **interpreted** language[cite: 6]. Instead of manually compiling code into machine code before running it, Python reads your instructions, converts them into **bytecode**, and runs them through the **Python Virtual Machine (PVM)**[cite: 6].

You can run Python in two main ways:
- **Interactive Mode (REPL):** Type single lines after `>>>` and see immediate results[cite: 6].
- **Script Mode:** Save code in a `.py` file (like `hello.py`) and run the whole file from the terminal[cite: 6].
